# VB LAST EMPIRE: SURVIVAL — V0.3

เกมต้นแบบ Android แนวสร้างฐานและป้องกันซอมบี้ พัฒนาด้วย Godot 4.4.1

## ไอเทมมอลล์และฮีโร่ V0.3
กด ITEM MALL / HEROES ที่แถบซ้าย แบ่งเป็น SHOP, CRATES, HEROES และ BAG
- รับเหรียญในเกมเริ่มต้น 1,000 และกล่องฮีโร่ 3 กล่องครั้งเดียว (รองรับเซฟเก่า)
- ร้านขายกล่องฮีโร่ 200 เหรียญ, แพ็กทรัพยากร 80, เร่งฝึก 50, ชุดซ่อมฐาน 60
- กล่องให้ฮีโร่ 8 ตัว 4 ระดับ: เขียว 60%, ฟ้า 25%, ม่วง 12%, ทอง 3% แต่ละระดับมีฮีโร่ 2 ตัว โอกาสเท่ากัน
- ถ้าเปิด 29 กล่องติดกันไม่ได้ทอง กล่องถัดไปการันตีทอง 100% ทุกครั้งที่ได้ทอง ตัวนับเริ่มใหม่
- ฮีโร่ตัวแรกลงทีมอัตโนมัติ เปลี่ยนผู้บัญชาการได้ใน HEROES ช่วยเร่งยิงและลดความเสียหายฐาน
- สุ่มซ้ำได้ชิ้นส่วนเฉพาะตัว 10 ชิ้น อัปเลเวลใช้ 20 คูณเลเวลปัจจุบัน เลเวลสูงสุด 5
- ชนะการป้องกันได้รับเหรียญ 120 + จำนวนชัยชนะคูณ 5 และทุก 3 ชัยชนะได้กล่องเพิ่ม 1
- ภารกิจเริ่มต้นให้เหรียญเพิ่ม 200 ต่อภารกิจ
- เป็นเหรียญในเกมเท่านั้น ยังไม่มีระบบจ่ายเงินจริง ข้อมูลเก็บในเครื่อง

## ระบบฐานเดิม
- ซอมบี้ 3D เดินบุกประตูฐาน ป้อมยิงพร้อมเส้นกระสุน และคลื่นศัตรูที่ยากขึ้น
- พลังฐาน การซ่อมแซม การเสียทหาร และเวลาพักหลังต่อสู้
- ฝึกทหารแบบนับถอยหลัง / อัปเกรดสิ่งก่อสร้างสัมพันธ์กับระดับ HQ
- ภารกิจเริ่มต้น 3 ขั้นพร้อมรางวัลที่รับได้ครั้งเดียว
- ลากเลื่อนแผนที่ แตะเลือกอาคาร บีบหรือกดปุ่มซูม บันทึกอัตโนมัติ
- อ่านเซฟเดิมทั้งชื่อฟิลด์ V1 และ V1.1
- แก้ Android SDK workflow ที่เคยหยุดเพราะแพ็กเกจ tools ถูกถอดออก

## เล่นบนมือถือ
ถือโทรศัพท์แนวนอน เลือก HQ แล้วกด UPGRADE รับรางวัลภารกิจ เลือก TRAIN รอทหารพร้อม แล้วกด DEFEND BASE
แถบคำสั่งซ้ายเลื่อนขึ้นลงได้ ปุ่ม REPAIR ใช้เหล็ก 60 แลกพลังฐาน 40
ข้อความในเกมรุ่นนี้เป็นภาษาอังกฤษ

## สร้าง APK
เข้า GitHub > Actions > Build Android APK > เลือกรอบล่าสุด
เมื่อสำเร็จ ดาวน์โหลด VB-LAST-EMPIRE-APK ใน Artifacts แล้วแตก ZIP เพื่อติดตั้ง APK
เป็น debug APK สำหรับทดสอบ ยังไม่ใช่รุ่นเผยแพร่ Play Store
รุ่น V0.2 สร้างด้วยกุญแจ debug ชั่วคราว จึงอาจติดตั้ง V0.3 ทับไม่ได้ กรุณาอย่าเพิ่งถอนรุ่นเก่าหากต้องการเก็บเซฟ (การถอนทำให้เซฟหาย) ตั้งแต่รอบนี้ workflow เก็บกุญแจ debug ผ่าน cache เพื่อใช้กับการอัปเดตรอบถัดไป แต่หาก cache หายลายเซ็นอาจเปลี่ยนได้
